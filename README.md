# Introdução à Ciência de Dados para Saúde

Este repositório foi criado como parte da disciplina **Introdução à Ciência de Dados para Saúde**.  
O objetivo é aplicar conceitos fundamentais de ciência de dados no contexto da saúde, explorando desde a coleta e tratamento de dados até a análise e visualização de informações.

---

##  Objetivos
- Compreender o ciclo de vida dos dados em saúde.  
- Realizar limpeza, transformação e integração de bases de dados reais.  
- Aplicar técnicas exploratórias e estatísticas em dados clínicos e epidemiológicos.  
- Utilizar ferramentas computacionais e boas práticas de versionamento de código.
